## Supplied Artwork

The original files stay under `Original Artifacts/`, with their filenames unchanged so the collection can still be matched to the material I supplied.

[Tycoon Tex – With Text](../Original%20Artifacts/Tycoon%20Tex%20-%20With%20Text.jpg) is the full artwork with the title. [Tycoon Tex – No Text](../Original%20Artifacts/Tycoon%20Tex%20-%20No%20Text.jpg) is the artwork variant without it. [Tycoon Tex Image](../Original%20Artifacts/Tycoon%20Tex%20Image.jpg) is a scan of the printed artwork and title.

The [Tycoon Tex Cassette Inlay](../Original%20Artifacts/Tycoon%20Tex%20Cassette%20Inlay.jpg) shows the cassette cover, artwork, description and gameplay screenshots. The correct Tycoon Tex scan replaced an unrelated cassette image that was stored under this filename. Page 5 of the scrapbook has another scan of the inlay.

![Tycoon Tex cassette inlay](../Original%20Artifacts/Tycoon%20Tex%20Cassette%20Inlay.jpg)

I haven't inferred any authorship, publication date or reproduction history for the artwork variants from their filenames alone.

## Press Scrapbook

[Scrapbook – C16](../Original%20Artifacts/Scrapbook%20-%20C16.pdf) is a 17-page, image-based PDF covering several games and related Gremlin and Micro Projects material. The page numbers below are positions in the PDF, not printed magazine page numbers.

| PDF page | Visible material                           |
| -------- | ------------------------------------------ |
| 1        | Xargon Wars packaging and Gremlin material |
| 2–4      | Gremlin publicity and press cuttings       |
| 5        | Tycoon Tex and Petals of Doom inlays       |
| 6–8      | Gremlin and Micro Projects documents       |
| 9–10     | Reviews and related C16 press cuttings     |
| 11       | Tycoon Tex review and related games        |
| 12       | Tycoon Tex review and C16 coverage         |
| 13       | Dork's Dilemma packaging and cuttings      |
| 14       | Gremlin multi-game advertisement           |
| 15–16    | C16 Collection review pages                |
| 17       | Compilation packaging including Tycoon Tex |

The Tycoon Tex cassette inlay is on **page 5**, on the left of the scanned sheet, with its artwork, title, game description and playing instructions. Pages **11–12** have reviews that go with it. I haven't catalogued every magazine or date, because the scrapbook mixes cuttings and the attribution is incomplete in places.

## Supplied Game and Screenshot

[tycoon_tex.prg](../Original%20Artifacts/tycoon_tex.prg) is the running game I have. It is 8,662 bytes, loads at `$1001` and holds a BASIC `SYS 4109` stub followed by compressed data. The verification script runs it and compares the decompressed memory with the rebuilt source version. It's there for comparison and contributes no bytes to the rebuilt game.

[tycoon_tex_main.jpg](../Original%20Artifacts/tycoon_tex_main.jpg) is a gameplay screenshot I supplied. It's a visual reference, not a capture of the rebuilt project.

`docs/images/restored-title.png` and `docs/images/restored-gameplay.png` are VICE screenshots of this project's source-built PRG, taken during verification on 20 October 2026.
