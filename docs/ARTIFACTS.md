## Press Scrapbook

[Scrapbook – C16](../Original%20Artifacts/Scrapbook%20-%20C16.pdf) is a 17-page, image-based PDF covering several games and related Gremlin/Micro Projects material. The page numbers below are PDF page positions, not printed magazine page numbers.

| PDF page | Visible material                           |
| -------- | ------------------------------------------ |
| 1        | Xargon Wars packaging and Gremlin material |
| 2–4      | Gremlin publicity and press cuttings       |
| 5        | Tycoon Tex and Petals of Doom inlays       |
| 6–8      | Gremlin and Micro Projects documents       |
| 9–10     | Reviews and related C16 press cuttings     |
| 11       | Tycoon Tex review and related games        |
| 12       | Tycoon Tex review and C16 coverage         |
| 13       | Dork's Dilemma packaging and cuttings      |
| 14       | Gremlin multi-game advertisement           |
| 15–16    | C16 Collection review pages                |
| 17       | Compilation packaging including Tycoon Tex |

The actual Tycoon Tex cassette inlay is on **page 5**, on the left of the scanned sheet. It includes its artwork, title, game description, and playing instructions. Pages **11–12** are useful companion reviews. Magazine identities and dates are not comprehensively catalogued because the scrapbook combines cuttings and the visible attribution is incomplete in places.

## Supplied Game and Screenshot

[tycoon_tex.prg](../Original%20Artifacts/tycoon_tex.prg) is the supplied running game. It is 8,662 bytes, loads at `$1001`, and contains a BASIC `SYS 4109` stub followed by compressed data. The verification script runs it and compares decompressed memory with the rebuilt source version. It is a comparison input, not a source of bytes for the rebuilt game.

[tycoon_tex_main.jpg](../Original%20Source%20Recovered/tycoon_tex_main.jpg) is the supplied gameplay screenshot. It provides a visual reference but is not a capture of the rebuilt project.

The separately saved `docs/images/restored-title.png` and `docs/images/restored-gameplay.png` are VICE screenshots generated from this project's source-built PRG during verification on 20 October 2026.
